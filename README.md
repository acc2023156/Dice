# 六子骰（Dice）— 傳統骰子下注遊戲（模擬版，RTP 98%）

**線上試玩：https://acc2023156.github.io/Dice/**

> 本專案使用**模擬遊戲幣**，不涉及真實金錢，僅供遊戲開發與演示。

把 Stake Dice「0–100 滑桿、Roll Over/Under」改成直覺的實體骰子玩法：選 1–6 顆骰子，押總點數、某個點數出現幾顆，或豹子。

## 玩法

| 玩法 | 說明 | 例 |
|---|---|---|
| 總點數 | 所有骰子加總「剛好／以上／以下」某數；「大」「小」一鍵選好約一半機率 | 3 骰 總點 ≥ 11（50%，1.96×） |
| 指定點數 | 某個點數出現「剛好／至少／最多」幾顆 | 3 骰 至少 1 個 6（42.13%，2.33×） |
| 豹子 | 所有骰子同點；可押任意或指定點數（≥ 2 顆骰） | 3 骰 任意豹子（2.78%，35.28×） |

- 畫面下方的**分布圖**是一張長條圖：每種結果一根長條，越高越常開出，綠色 = 會贏；點長條可直接設定目標。
- 下注前就顯示勝率、倍數、贏得派彩。
- 骰子為 CSS 3D，拋起 → 落桌彈跳 → 翻滾到結果點數，附落桌音效；1、4 點為紅色（傳統骰子）。

## 數學（RTP 98%）

- n 顆骰子共有 6ⁿ 種等機率結果；勝率 `P = 會贏的結果數 / 6ⁿ`。
  - 總點數：逐顆摺積算出每個總和的組合數。
  - 指定點數出現 k 顆：`C(n, k) × 5ⁿ⁻ᵏ`。
  - 豹子：任意 6 種、指定 1 種。
- 倍數 `= 0.98 / P` → **任何**注項的期望回報都是 98%（莊家優勢 2%）。
- 勝率 > 97% 的注項不接受（倍數會低於 1.01×）。派彩向下取整到 0.01。

## 公平性（Provably Fair）

- 每局開始前公開 `SHA256(serverSeed)`，結束後公開 serverSeed。
- 亂數：`SHA256(serverSeed:clientSeed:nonce:cursor)` 每 8 個 hex 轉成一個 0~1 浮點數。
- 第 i 顆骰子 = `floor(float_i × 6) + 1`。
- 頁面「公平性」視窗可輸入任一局的種子重新計算骰子；客戶種子可自行修改。

## 功能

| 項目 | 說明 |
|---|---|
| 手動 | 擲骰（點托盤也可以）；空白鍵擲骰，↑↓ 調整目標 |
| 自動 | 局數、贏／輸後加碼 %、獲利／虧損停止 |
| 快速擲骰 | 縮短動畫；系統設定「減少動態效果」時自動啟用 |
| 紀錄 | 最近 100 局、勝率、淨損益、實際回報率；存在 localStorage |
| 賠率表 | 目前骰子數與玩法下，每個目標「剛好／以上／以下」的倍數 |
| 大廳 | 左上「‹ 返回大廳」預設回 Boss88VIP 大廳；網址帶 `?return=<大廳網址>` 時改回該網址（僅接受 acc2023156.github.io 與本機） |
| 跑馬燈 | 會員列下方、寬 26 個字；「六子骰」品牌名穿插隨機吉祥話 |
| 自適應 | 手機（≤900px）托盤在上、主按鈕固定在底部 |

## 專案結構

```
index.html          版面
css/style.css       樣式（深色、RWD、3D 骰子）
js/sha256.js        同步 SHA-256
js/engine.js        遊戲引擎：機率、倍數、擲骰、結算（不碰 DOM，Node 可跑）
js/sound.js         Web Audio 合成音效
js/ui.js            畫面、擲骰動畫、分布圖、自動投注、紀錄、公平性視窗
tools/rtp-test.js   驗證：node tools/rtp-test.js（窮舉 6ⁿ 核對全部注項 + 蒙地卡羅）
```
